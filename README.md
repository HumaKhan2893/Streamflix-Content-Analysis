# StreamFlix Content Analysis

## 📌 Project Overview

StreamFlix Content Analysis is a data analytics project focused on understanding
content performance, subscriber behavior, viewing patterns, and user engagement
for a streaming platform.

The project uses Python, Pandas, and Power BI to clean, analyze, and visualize
streaming platform data and generate meaningful business insights.

## 🎯 Project Objectives

- Analyze subscriber behavior and engagement
- Identify high-performing content and genres
- Analyze viewing trends and watch hours
- Calculate important business KPIs
- Understand content and subscriber performance
- Create an interactive Power BI dashboard

## 🛠️ Tools & Technologies

- Python
- Pandas
- Jupyter Notebook
- Power BI
- Microsoft Excel
- SQL
